## 代表作：[《解域》· jieyu-tactics](https://github.com/copperbookworm/jieyu-tactics)

2D 垂直俯视的 **20v20 小队战术射击游戏**。已产出 Android 发布包并在真机完成验证。

- **工程规模**：205 个 GDScript 文件 / 38,578 行；单元测试 62 个脚本（断言 2,205 项）、集成冒烟 317 项，两套全绿
- **方法**：把重复流程固化成 9 个自研 agent 技能（真机验证、性能采样、几何门禁、发布工程、资产流水线…），每次提交都要过两套 headless 测试
- **节奏**：8 天完成 100 个版本、120+ 次提交，代码与文档同步推进
